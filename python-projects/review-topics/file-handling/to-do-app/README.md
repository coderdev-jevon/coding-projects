# Flask Task Manager
A simple web-based task CRUD application built with Flask.
Supports create, delete, edit, toggle completion status, and a public JSON API.
All data persistently stored inside a local JSON file.

## Features
- View all tasks on homepage
- Add new tasks
- Delete existing tasks
- Edit task name
- Toggle completed status
- JSON API endpoint to fetch all tasks
- Data persistence via tasks.json

## Tech Stack
- Python 3
- Flask
- HTML / CSS
- JSON for local storage
- Pathlib for file handling
